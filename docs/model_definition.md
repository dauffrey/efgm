# EFGM Model Definition

```text
T × E → Et → F ± e → A|M
```

## Operational equation

```text
F = (T × E × Fq) / (1 + e)
```

## Variables

| Variable | Meaning |
|---|---|
| T | Time, iteration continuity, or observation maturity |
| E | Capability, tooling, compute, or operational capacity |
| Fq | Flow quality |
| e | Entropy load |
| F | Coherent flow score |
