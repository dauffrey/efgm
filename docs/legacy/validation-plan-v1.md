# Legacy EFGM v1 Validation Plan Summary

The original validation plan evaluated the coherent-flow model built around:

```text
F = (T × E × Fq) / (1 + e)
```

and the later geometric-mean v1 compatibility implementation.

It focused on aggregate entropy metrics such as contradiction density, uncertainty variance, memory fragmentation, recursion instability, and context decay; and flow-quality metrics such as task completion consistency, reasoning continuity, semantic coherence, and verification success rate.

That plan has been superseded for new research by `../../validation/test-plan.md`, which validates EFGM v2 using falsification, blinded scoring, baselines, ablations, sensitivity tests, and sealed holdouts.

The repository history remains the authoritative record of the full earlier document.
