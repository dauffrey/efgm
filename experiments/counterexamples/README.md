# Counterexamples

Retain cases where EFGM produces an incorrect ranking, misleading classification, unstable score, poor construct separation, or materially worse result than a simpler baseline.

A counterexample should include the case/evidence, expected or independently established judgment, EFGM version/configuration, observed failure, suspected mechanism, and whether a later candidate resolves it without regression elsewhere.

Counterexamples must not be deleted merely because they are inconvenient to the model narrative.
